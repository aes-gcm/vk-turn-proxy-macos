# VK Turn Proxy 0.1.0 для macOS

Первый установочный релиз для **macOS 13 Ventura и новее**. Включены универсальные бинарники для **Apple Silicon и Intel**.

## Установка

- **`.pkg`** — обычный мастер установки в Applications.
- **`.dmg`** — образ с приложением, ссылкой Applications, установщиком и инструкцией на русском.
- **`SHA256SUMS.txt`** с префиксом версии — контрольные суммы обоих файлов.

Перед обновлением отключите соединение и завершите старую версию. После установки откройте **VK Turn Proxy** из Applications; управление доступно через значок в строке меню → **«Открыть окно…»**.

Импортируйте собственный профиль во вкладке «Сервер», войдите в VK и укажите ссылку на звонок. При первом подключении подтвердите установку сетевой службы паролем администратора. Go, Xcode и отдельный WireGuard устанавливать не требуется. Доступ к серверу и личные профили в релиз не входят; существующие настройки сохраняются.

## Что включено

- Свежая сборка SwiftUI-приложения и Go-ядра из исходников для обеих архитектур.
- Проверка наличия ядра, подписи и структуры установочных файлов.
- Иконка приложения, лицензия и инструкция первого запуска.
- Установка сетевой службы в системную папку с проверкой правила sudoers; корректная обработка пробелов, кавычек и апострофов в путях.

## Подпись и проверка

Приложение подписано ad-hoc; установщик не имеет Developer ID Installer, **нотарификация Apple не выполнена**. Если macOS блокирует запуск, после попытки открытия используйте **«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»**, если доверяете загрузке. [Инструкция Apple](https://support.apple.com/en-us/102445). Отключать Gatekeeper целиком не нужно.

Проверки сборки, структуры PKG/DMG и автоматические тесты выполнены на Apple Silicon. Нативная работа на физическом Intel Mac, установка на чистую macOS и полноценное VPN-подключение из этой сборки отдельно не проверялись.
